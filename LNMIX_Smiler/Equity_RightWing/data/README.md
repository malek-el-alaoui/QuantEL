# Equity-only input datasets

This project runs only equity / equity-index smile snapshots:

- EURO STOXX 50 historical multi-maturity smile
- SPX short-dated smile
- AAPL short-dated smile
- NVDA short-dated smile
- TSLA short-dated smile

The former EUR/USD test file is intentionally excluded from this version because the right-wing rule implemented here is specifically an equity-skew extrapolation rule.
